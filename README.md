## To run the file, open a new terminal and run the following:
##  .\env\Scripts\activate
##  python manage.py migrate
##  python manage.py runserver
## This will run the project on a local host
##
## There's no seeded demo account — the database isn't committed to the repo.
## Use the Sign Up page to create your own account (no email verification step,
## you're logged straight in).
##
## The support contact form sends email via Gmail SMTP. To enable it locally,
## set EMAIL_HOST_USER and EMAIL_HOST_PASSWORD as environment variables before
## running the server (see core_setup/settings.py for details). Without them,
## the rest of the app still works — only the support form's email send will fail.
